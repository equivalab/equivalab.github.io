# Equiva Lab homepage

一个零依赖、响应式的 Equiva Lab 团队网站。内容结构参考学术实验室常见的信息组织，视觉采用明亮背景、克制字号、圆角内容卡片与低饱和蓝绿色渐变。

网站包含：首页、研究成果、团队成员、团队新闻与加入我们页面；招新考核内容直接整合在加入我们页面中。

当前招新报名与材料提交统一跳转至 `https://review.su-do.cn/`；主站仅展示考核说明，不保存报名信息与提交材料。

## 本地预览

直接打开 `index.html`，或在目录中运行任意静态文件服务器，例如：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 上线前需要替换

- `team.html` 中的真实成员信息与个人主页
- `news.html` 中后续发布的团队动态
- 页脚中的学校、机构与备案信息（如适用）

页面支持中英文切换、当前章节高亮、移动端导航、滚动入场动画、减少动态效果的系统偏好，以及基于 Canvas 的等价表征动态示意图。

## 成果维护

网站不提供公开的成果提交或管理入口。成果由拥有仓库写入权限的团队成员维护：

1. 编辑 `content/results.js` 中的 `window.EQUIVA_RESULTS` 数组。
2. 按文件内的字段模板填写论文、项目或开源成果；页面会自动按年份倒序分组。
3. 提交并推送到 `main` 分支，GitHub Pages 更新后自动公开。

请勿在该文件中存放未公开或敏感信息；GitHub Pages 和公开仓库中的前端文件均可被访客读取。
